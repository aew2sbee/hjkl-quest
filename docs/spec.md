## 1. 基本方針

| 項目 | 内容 |
|---|---|
| 対象ユーザー | Vim を一度も触ったことがない完全な初心者 |
| 言語 | 日本語のみ（UI と説明文は日本語、練習テキストは英語）。言語の振り分けや切り替えは持たない |
| 判定 | **指定コマンドの使用を必須**とする（結果が合っていても別の方法なら再挑戦を促す） |
| 見た目 | ポップなダーク UI ＋ エディタ内部は本物の Vim らしさを維持。色は Vim のグリーンを基調 |

| 開始方法 | エディタ欄のシェル画面で `vim` と入力して Enter → Vim 起動 |
| 対応端末 | PC（物理キーボード）。スマホ対応は [plan.md](plan.md) の M4 |

## 3. 画面

### トップページ
- 最初に大きな `h` `j` `k` `l` のキーと小さな地図を置く。キーボードかボタンで押すとキーが沈み、地図のカーソルが動く。黄色い `*` に届くと次の `*` が出る。説明を読む前に「押すと動く」を体験させるため
- その下に見出しと、1.1 から始めるボタン
- 7つの章の一覧。遊べるレッスンはリンク、まだのものは「準備中」

### レッスン画面
```
┌──────────┬──────────────────────────────────┐
│ CHAPTERS │ QUEST · 1.3                      │
│ 01 基本   │ x で余計な文字をやっつけよう       │
│  ✓1.1    │ 説明文（1〜2行）                  │
│  ▶1.3    │ ✅ / 🔶 / ⬜ TODO（縦並び）       │
│ 02 🔒    │               [ヒント][やり直す]  │
│ ...      ├──────────────────────────────────┤
│          │ ~/quest $ vim ▮                  │
│          │ （起動後は Vim 画面。高さは練習文の │
│          │   行数に合わせて自動で変える）      │
│          │ NORMAL  lesson1-3.txt   5,3      │
│          │ 押したキー: [j][j][x]             │
└──────────┴──────────────────────────────────┘
```

- **チャプター一覧**: クリア済み ✓、現在 ▶、未解放 🔒。幅が狭いときは現在のチャプターを横スクロールで表示
- **TODO**: 現在の課題を強調。達成するとチェックが弾むように付く。TODO が多い課題ではクリア済みを折りたたむ
- **黄色の目印**: 今の TODO が見る場所を、エディタの中で黄色く光らせる。移動のレッスンは目的地の1文字（`target`）、直すレッスンは直す単語（`mark`、編集で位置がずれるので毎回探し直す）。どの文字を消すかまでは示さない。問題文の `*` も同じ黄色にそろえる
- **最初からやり直すしかないとき**（レッスンの `stuck`）: トーストで1回伝え、そのあいだ「↺ やり直す」ボタンをオレンジで目立たせ続ける。ボタンの動きは最初の2回だけ
- **エディタ**: 暗い背景、行番号、`~`、ステータスライン、コマンドライン。モードは色分け（NORMAL 青 / INSERT 緑 / VISUAL 紫）
- **押したキーの表示**: 直近12キー。誤ったキー（矢印など）はオレンジで表示
- **褒めトースト**: 画面下からふわっと出る。TODO 達成で小、レッスンクリアで紙吹雪＋★評価
- **IME 警告**: 日本語入力のオンを検出したら「半角英数に切り替えてね」と表示

### シェル画面（レッスン開始時）
- 1.2 以降のレッスンはシェル画面から始める（レッスンの `shell`）。起動を習う前の 1.1 だけは Vim 画面から始める
- `~/quest $ ▮  ← vim と入力して Enter`
- `vim` または `vim <レッスンのファイル名>` で起動する。起動するたびに練習文は最初の状態に戻る
- ほかのファイル名なら、レッスンのファイル名で開くよう案内する。ほかのコマンドなら `zsh: command not found: xxx` とヒントを表示する
- 入力した文字はテキストとして表示し、HTML として解釈しない
- Vim で `:q!` を実行するとシェル画面に戻る。`:q` だけでは終了せず、`!` を付けるよう伝える
- Chapter 1 は毎回入力。Chapter 2 以降は入力済みで Enter だけで起動（案）
- `:wq` を習った後のレッスンは、`:wq` でシェルに戻るとクリア（案）

### 誤った方法で達成したとき
- 「テキストは直せました！ でも今回は `dw` で挑戦してみよう」と表示し、[もう一度] ボタンで課題を始め直す
- 不正解という言葉は使わない

## 4. レッスンの定義

1 レッスン 1 ファイルで、練習テキスト・判定と日本語の文言をまとめて定義する。中身は [lessons.md](lessons.md) の設計表から作る。

```
src/lessons/1-3.ts         練習テキスト・TODO の判定・必須コマンド・最短キー数・タイトル・説明・TODO 文・ヒント
```

```ts
// src/lessons/1-3.ts
export default defineLesson({
  id: "1-3",
  buffer: [
    "---> My doog likess to chasee red balls.",
  ],
  todos: [
    {
      id: "fix-dog",
      check: (s) => s.line(0).includes("My dog "),
      require: { commands: ["x"], forbid: ["arrows"] },
    },
    {
      id: "fix-likes",
      check: (s) => s.line(0).includes(" likes to "),
      require: { commands: ["x"], forbid: ["arrows"] },
    },
    {
      id: "fix-chase",
      check: (s) => s.line(0) === "---> My dog likes to chase red balls.",
      require: { commands: ["x"], forbid: ["arrows"] },
    },
  ],
  optimalKeys: 32, // シェルの vim と Enter（4キー）＋ 行頭から hjkl と x だけで直したときのキー数
});
```

### 判定の仕組み
- **バッファ**: テキストが目標どおりか（lessons.md の「文」）
- **カーソル・モード**: 指定の位置・モードか（lessons.md の「位置」）
- **キー履歴**: `vim-keypress` / `vim-command-done` イベントでコマンドを記録し、`require` を満たしたかを見る（lessons.md の「実行」と「必須」）
- `2dw` と `dwdw` のように複数の書き方がある課題は、課題ごとに許可するものを指定する
- **使えるキー**: レッスンごとに Vim に渡すキーを決める（`keys`）。`Esc` はいつでも使える。それ以外のキーは Vim に渡さず、矢印キーなら「hjkl で！」、ほかは「まだ習っていないキー」と伝える。Tab と、Alt・Meta を押しながらのキーはブラウザに任せる
- **挿入モードのキー**: 挿入モードのあいだは、文字・Space・Backspace をそのまま Vim に渡す（入力した文字はコマンドではなくテキストになるため）。Enter は行が分かれるので止める。止めたキーには、習っていないキーではなく、挿入モードで使えるキーと Esc で戻ることを伝える
- **日本語入力**: IME がオンのまま押したキー（`key` が `Process`）は Vim に渡さず、日本語入力をオフにするよう伝える
- **マウス**: エディタ内のクリックではカーソルを動かさない。クリックで目的地に届いてしまうため
- TODO は順番どおりに達成する。先の TODO の条件を先に満たしても数えない

### 進捗データ（localStorage）
キーには `src/env.ts` の `storagePrefix` を付ける。

```ts
{ version: 1, lessons: { "1-3": { cleared: true, stars: 3, bestKeys: 32 } } }
```

## 5. 評価と演出

- TODO 達成: 褒めトースト（言葉はランダム）
- レッスンクリア: 紙吹雪、★評価（最短キー数との差・ヒント使用の有無で ★1〜3）
- クリアのポップアップ: 最後の TODO から少し待って開く。キー数（と最短）を見せ、[もう一度] と [続ける] を選ばせる。[続ける] は次のレッスンへ進む。次のレッスンが準備中か、最後のレッスンのときはトップページに戻ると書いておく
- 矢印キーを使ったら「矢印キーじゃなくて hjkl で！」と伝える
- `prefers-reduced-motion` のときはアニメーションを止める
- 効果音は M3 以降（デフォルトはオフ）
